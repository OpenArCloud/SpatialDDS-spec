One bus for spatial data

SpatialDDS is an open protocol for real-time exchange of spatial world models. Robots, vehicles, AR clients, sensors, and digital twins publish and consume the same typed spatial data — poses, detections, anchors, zones, maps — on one shared bus.

Typed spatial data

Poses, detections, anchors, zones, and maps as typed messages that carry uncertainty, attribution, and provenance — not just coordinates. Heavy content rides by reference; the bus stays light.

Discovery by location

Ask what covers here. Geohash-indexed discovery over DNS and well-known HTTP resolves a place to the services, anchors, and content that cover it — no registry, no gatekeeper.

Every system speaks it

DDS where machine-tempo QoS matters. Plain GET and WebSockets for browsers. Carried over ROS 2, MQTT, and MCAP recordings. The data model is one; the transports are many.

Proven in the open

Machine-checkable conformance suites run against public datasets, and public reference deployments you can visit — every claim in the spec is one someone can re-run.
